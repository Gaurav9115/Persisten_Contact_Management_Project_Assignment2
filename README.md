# Contact Management System using Java Servlets and JSP

## Project Description

The Contact Management System is a dynamic web application developed using Java EE technologies following the MVC (Model-View-Controller) architecture. The application allows visitors to submit their contact information through a user-friendly web form and enables administrators to manage and view submitted contacts efficiently.

The system implements server-side and client-side validation to ensure data accuracy and integrity. User details such as Name, Email Address, and Phone Number are validated before being stored in the application's session memory using HTTP Sessions. The application provides meaningful success and error messages to enhance user experience.

The project consists of Java Servlets for request processing, JavaBeans for data modeling, JSP pages for presentation, and utility classes for validation. Security measures such as escaping user-generated content are implemented to protect against Cross-Site Scripting (XSS) attacks.

### Key Features

* Add and manage contact information.
* Form validation for Name, Email, and Phone Number.
* Real-time user feedback and error handling.
* Session-based contact storage.
* Contact listing with search functionality.
* Responsive user interface using HTML, CSS, and JavaScript.
* MVC-based architecture for better maintainability and scalability.
* Secure handling of user input.

### Technologies Used

* Java
* Java Servlets
* JSP (Java Server Pages)
* JSTL
* HTML5
* CSS3
* JavaScript
* Apache Tomcat
* HTTP Session
* MVC Design Pattern

### Project Outcome

The application successfully demonstrates the implementation of a Java EE web application using Servlets and JSP. Users can submit contact details, administrators can view and manage contacts, and all data is maintained during the active session. The project serves as a strong foundation for future enhancements such as database integration using MySQL and advanced contact management features.
